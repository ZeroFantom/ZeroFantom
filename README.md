## 01 / Основной проект

### [MysticEgo](https://github.com/ZeroFantom/MysticEgo)

[![MysticEgo Orchestra](https://raw.githubusercontent.com/ZeroFantom/MysticEgo/main/frontend/scripts/social-art/orchestra.png)](https://github.com/ZeroFantom/MysticEgo)

Экосистема управления компьютерами, инфраструктурой и персональными ИИ-ассистентами.

| Инфраструктура | Персональная среда |
| :--- | :--- |
| Организации, площадки и рабочие станции | Профили, чаты и уведомления |
| Диагностика и распределённое управление | ИИ-ассистент и VRM-аватары |
| Развёртывание и обновление компонентов | MCP и экспериментальная автоматизация интерфейсов |

**Стек:** C# / .NET · ASP.NET Core · TypeScript / React · Electron · Windows / Linux

Проект развивается в рамках BETA7. Статус конкретных функций, экспериментальные ограничения и инструкции — в [документации](https://github.com/ZeroFantom/MysticEgo#readme). Наличие реализации в исходном коде не означает готовность выпущенного продукта.

## 04 / Вклад в Open Source

### [VkNet](https://github.com/vknet/vk)

Вклад в стороннюю библиотеку VK API для .NET: переработка перегрузок `Delete` и `DeleteAsync` для удаления сообщений, уточнение допустимых параметров и согласование синхронной и асинхронной реализации.

[PR #1258 — принят 9 января 2023 года](https://github.com/vknet/vk/pull/1258) · [Коммит](https://github.com/vknet/vk/commit/8cade8a427950c43a7f08ca64aa5e25448ec6797)

### [Avalonia.GIF](https://github.com/ZeroFantom/Avalonia.GIF)

Модифицированный форк [AvaloniaUI/Avalonia.GIF](https://github.com/AvaloniaUI/Avalonia.GIF). Исходная библиотека — работа её авторов, включая Jumar Macato (MIT). Мои изменения ограничиваются собственными доработками; их точный объём ещё предстоит выделить сравнением версий.
